How I work

Sketch to live

The same five steps, whether it's a dashboard, a restaurant site or a landing page.

  1. 01

    Understand

    Who is this for, and what do they need to get done?

    Research
  2. 02

    Figma
  3. 03

    Figma
  4. 04

    Build

    Responsive HTML, CSS and JavaScript, with Node.js and MySQL behind it.

    Code
  5. 05

    Measure
